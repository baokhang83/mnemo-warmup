# v0.2.5 release: switching the README

The README stays on the released 0.2.0 Helm-chart path until v0.2.5 exists, because the annotation path (`inject`, the native launcher, ECR workload identity) is not in any released CLI or tools image yet. Everything else for the v0.2.5 documentation is already merged.

`docs/release/README.v0.2.5.md` is the README to publish. Its commands were run against the CLI built from `main` (the preview, `helm template` with the post-renderer, copying the CLI out of a tools image, the `jq` measurement); the image tag `0.2.5` and the git tag `v0.2.5` are the only things that cannot resolve before the release.

## At release time

1. Tag and publish `v0.2.5` (tools image `ghcr.io/baokhang83/mnemo-warmup-tools:0.2.5`, chart if it changed).
2. Confirm the tag exists, then run the draft's commands once against it:
   - `docker create ghcr.io/baokhang83/mnemo-warmup-tools:0.2.5` and `docker cp` as in step 0; `mnemo-warmup --version` prints `0.2.5`;
   - `git clone --branch v0.2.5` and `scripts/e2e-kind-inject.sh temurin`.
3. `cp docs/release/README.v0.2.5.md README.md`, then delete the leading HTML comment.
4. Check every link and anchor in `README.md` and `docs/` resolves (the helm-chart page links back to `../README.md`).
5. The Helm-chart setup that the old README held is already in `docs/helm-chart.md`; the new README links to it, so nothing else needs moving.
6. Delete `docs/release/` (this folder) or keep it as a record.

## Things the draft changes from the earlier outline

- Three annotations are required (`enabled`, `store`, `exit-mode`), not two. The injector stops with `missing warmup.mnemo.io/exit-mode` otherwise.
- The preview lists names and changed fields; it does not prompt for missing values.
- The trainer's ServiceAccount is generated and cannot be annotated for IRSA by the injector today ([limitation](../operations.md#known-limitations)).
